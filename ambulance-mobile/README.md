# Ambulance

### Описание проекта

Приложение, предоставляемое компанией ООО "ЛИДЕР-МЕД ГРУПП", предназначено для бригад скорой помощи, включающих администратора, водителя и доктора. Основные функции приложения:
- Управление рабочими сменами — начало и завершение смены.
- Прием вызовов и распределение задач для бригады.
- Отправка бригады на встречу с клиентом.
- Оказание медицинских услуг клиентам.
- Отслеживание и обновление статусов выполнения вызова через приложение.
- Назначение медикаментов пациентам.
- Подготовка стационаров.

### Инструкция для разработчиков

Для начала разработки необходимо настроить Firebase для Android и iOS с помощью FlutterFire CLI. Следуйте шагам ниже:

#### Настройка проекта через FlutterFire CLI:

   - Из корневой директории вашего проекта выполните следующую команду:
     ```bash
     flutterfire configure
     ```
   - Следуйте интерактивным инструкциям:
     - Создайте новый проект с названием, например, `reset-med-dev`
     - Выберите только **Android** и **iOS** (другие платформы не выбирайте)
     - Введите следующее имя для Android пакета: `ru.resetmed.ambulance`
     - Введите то же самое для iOS Bundle ID: `ru.resetmed.ambulance`

После этих шагов проект будет готов к разработке с использованием Firebase-сервисов.
